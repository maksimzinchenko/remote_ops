# Remote Ops

Кроссплатформенный SSH-клиент на Flutter 3.47.6 / Dart 3.13.5. Приложение подключается к серверу напрямую, без backend и без прокси.

Постоянных SSH-сессий нет. Соединение открывается только на время одного блока команд, шаги выполняются по порядку, приложение ждёт завершения и закрывает соединение. Сейчас это один сервер за запуск. Параллельный запуск на нескольких серверах позже можно собрать из тех же независимых запросов; общий интерфейс такого запуска пока не делаем.

Язык интерфейса берётся из системы. Сейчас есть английский и русский; если язык системы другой, используется английский. Строки лежат в `lib/l10n`, код ошибки не содержит готового текста.

## Что есть в этой версии

- добавить и удалить профиль сервера;
- пароль только в защищённом хранилище ОС;
- проверить подключение без сохранения профиля;
- выполнить блок команд из файла и дождаться результата;
- проверить SSH host key, не принимать изменившийся ключ молча.

## Слои

```
UI → application → domain → infrastructure
```

UI не вызывает `SSHClient`. Блоки команд читаются из `assets/commands` и не редактируются в приложении.

## Запуск

```
flutter pub get
flutter run
```

Linux: для секретов нужен Secret Service (`libsecret`). macOS: `com.apple.security.network.client`. Android: `INTERNET`.
